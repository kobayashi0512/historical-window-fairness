# Data availability

This repository intentionally excludes third-party raw interaction records. The code consumes public inputs obtained from their original sources; their URLs, checksums, retrieval notes and usage reminders are recorded in data/DOWNLOAD_MANIFEST.json.

No individual-level or institutional record is redistributed here. Users must independently review and comply with every upstream source's terms, required citation and any local ethics or data-governance requirements.

The repository includes only derived aggregate result tables and synthetic-stream summaries used by the manuscript.
